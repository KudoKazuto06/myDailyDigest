# 📰 myDailyDigest

myDailyDigest is a personal project I built to make staying up-to-date with news effortless. Instead of manually searching for news, I created a backend that fetches data from **News APIs** and **RSS feeds**, and an interactive React frontend to display news from various sources daily.  

---

### 🌟 Features
- Aggregates news from multiple sources automatically.  
- Interactive React frontend for browsing and reading news easily.  
- Backend built with Node.js to handle API calls and RSS feeds.  

### 🛠️ Tech Stack
- Frontend: React, TailwindCSS  
- Backend: Node.js, Express  
- Data Sources: NewsAPI, RSS feeds  

### 🚀 How to Run
1. **Backend**  
   ```bash
   cd backend
   npm install
   nodemon index.js
   ```
   (or `node index.js` if nodemon is not installed)  

2. **Frontend**  
   ```bash
   cd frontend
   npm install
   npm run start
   ```
3. Open your browser at `http://localhost:3000` to see the app in action.
